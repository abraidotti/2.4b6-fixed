# Which QuickMUD-Python bugs are in stock ROM 2.4b6

Generated by `python tools/triage.py` from [bugs.csv](bugs.csv). Don't edit this file by hand.

Porting QuickMUD to Python ([abraidotti/QuickMUD-Python](https://github.com/abraidotti/QuickMUD-Python)) turned up bugs in its C. QuickMUD is a
derivative of ROM 2.4b6, with add-ons (OLC, mob programs, boards, colour, copyover) and changes of its own, so
each bug was checked against the stock code at the [`stock-2.4b6`](https://github.com/abraidotti/2.4b6-fixed/tree/stock-2.4b6) tag: is the same function
there, with the same faulty lines?

**102 bugs from 49 issues:**

- **79 in stock ROM 2.4b6**, from 32 issues. These are what this repo fixes:
  **33 fixed so far**, and 46 left (12 wrong behaviour, 34 message).
- **1 stock, but different:** stock has the code, but the bug can't happen the same way.
- **22 QuickMUD only:** an add-on, or code QuickMUD changed. Not fixed here.

An issue with several bugs has a row for each, numbered as in the issue. A row with no number is the whole
issue. Links to stock code point at the function's first line at the tag. A stock bug's kind says what its
fix changes, and Fixed links the issue here that its fix closes. Bugs found while fixing these, and not from
QuickMUD-Python, are in [FIXES.md](https://github.com/abraidotti/2.4b6-fixed/blob/main/FIXES.md) only.

**Not examined:** stock code that QuickMUD replaced or removed (for example `note.c`, which QuickMUD's
boards replaced) was never read during the port, so its bugs, if any, aren't in this table. That code is
unexamined, not fixed.
